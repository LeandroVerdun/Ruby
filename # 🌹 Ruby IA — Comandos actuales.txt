* `reproduce [canción] de [artista]`

## 🌍 4. Selector de navegador

Ruby permite elegir qué navegador utilizar.

### Comandos

* `usá Chrome`
* `usa Chrome`
* `usar Chrome`
* `quiero usar Chrome`
* `usá Opera`
* `usa Opera`
* `usar Opera`
* `quiero usar Opera`

### Funcionamiento

* Chrome está disponible como opción.
* Opera GX está disponible como opción.
* Ruby guarda el navegador seleccionado en `commands/browser_config.json`.
* La selección se recupera al iniciar Ruby.
* Las aperturas y búsquedas utilizan el navegador elegido, según las pruebas realizadas.

**Estado:** Implementado y probado para Chrome y Opera GX.

**Pendiente de verificación:** comprobar que el cierre de pestañas y el enfoque de ventanas también funcionen correctamente con ambos navegadores.

## 🔄 8. Reinicio de Ruby

Ruby incorpora un comando para reiniciar el asistente desde la terminal sin tener que escribir manualmente `salir` y ejecutar de nuevo `python main.py`.

### Comandos previstos en la implementación actual

* `reiniciate`
* `reiníciate`
* `reinicia ruby`
* `reiniciá ruby`
* `reiniciar ruby`
* `reiniciar`

### Funcionamiento esperado

1. Ruby reconoce el comando.
2. Inicia una nueva instancia del programa.
3. La instancia anterior termina.
4. Ruby vuelve a mostrar su encabezado y queda lista para recibir instrucciones.

**Estado:** Reinicio básico implementado, pero requiere una mejora.

### Pendiente: reinicio elegante

* Evitar instancias duplicadas.
* Asegurar que el proceso anterior termine correctamente.
* Manejar errores si la nueva instancia no puede iniciarse.
* Mantener el directorio de trabajo correcto.
* Comprobar que las configuraciones guardadas sigan disponibles después del reinicio.
