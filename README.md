# Ruby IA ❤️

**Ruby IA** es un asistente personal desarrollado en Python, inspirado en la idea de tener una IA propia capaz de interactuar con el usuario y ayudarlo con tareas cotidianas desde su computadora.

El proyecto se encuentra en desarrollo y tiene como objetivo construir un asistente modular que combine comandos de voz, control del navegador, automatización del PC y, en el futuro, capacidades conversacionales más avanzadas.

## 🎯 Objetivos del proyecto

- [x] Crear una estructura modular en Python.
- [x] Implementar comandos básicos.
- [x] Abrir programas y páginas web.
- [x] Integrar funciones para buscar música en YouTube.
- [x] Implementar navegación y lectura de páginas web mediante Playwright.
- [x] Comenzar la integración del reconocimiento de voz con Vosk.
- [ ] Mejorar el reconocimiento y la ejecución de comandos de voz.
- [ ] Desarrollar un sistema de memoria.
- [ ] Integrar un modelo de lenguaje para conversaciones más avanzadas.
- [ ] Ampliar el control del PC y la automatización.
- [ ] Desarrollar una interfaz gráfica y una representación visual de Ruby.

*La lista refleja el progreso actual y se actualizará a medida que avance el proyecto.*

## 🛠️ Tecnologías utilizadas

- **Python** — lenguaje principal.
- **Vosk** — reconocimiento de voz local.
- **Playwright** — automatización y control del navegador.
- **yt-dlp** — búsqueda de música en YouTube.
- **Git y GitHub** — control de versiones y seguimiento del desarrollo.

## 🚀 Estado actual

Ruby IA funciona como un asistente ejecutado desde la consola de Python. Ya cuenta con comandos básicos, búsqueda de música, apertura de páginas web y funciones de navegación mediante Playwright. También se está trabajando en el reconocimiento de voz para permitir la interacción sin depender exclusivamente del teclado.

## 🗺️ Hoja de ruta
